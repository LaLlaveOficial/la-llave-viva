## Configuración

Crear un conector Google en Vercel Connect para la app OAuth de La Llave y vincularlo
a `la-llave-viva`, producción. Usar el UID real devuelto en `GA4_CONNECTOR_UID`;
no suponer que coincide con el nombre elegido. La URI de retorno de Vercel es
`https://connect.vercel.com/callback` y debe estar autorizada en Google Cloud.
Habilitar Google Analytics Data API en el proyecto Google Cloud existente.
La nueva autorización solicita `analytics.readonly`; Gmail y Ads no la sustituyen.
No guardar ni publicar el secreto OAuth en este repositorio.
