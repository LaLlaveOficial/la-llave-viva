# La Llave Viva Landing

Landing oficial para **La Llave I: Ciudad Central**.

## Desarrollo local

```bash
npm install
npm run dev
```

## Build para Vercel

```bash
npm run build
```

## Assets

Los archivos de imagen están en:

```txt
public/assets/la-llave-ciudad-central-hero.png
public/assets/la-llave-066-key.png
public/assets/la-llave-hazard-stripe.png
```

## Links Amazon

Cuando estén disponibles los enlaces definitivos de Kindle y tapa blanda, editar en `src/App.jsx`:

```js
const AMAZON_KINDLE_URL = "#";
const AMAZON_PAPERBACK_URL = "#";
```
